# 💍 Undangan Pernikahan Digital
Repositori ini berisi *source code* untuk template undangan pernikahan digital yang modern, elegan, dan responsif. Proyek ini dirancang agar mudah dikustomisasi oleh siapa saja yang ingin membuat website undangan pernikahan mereka sendiri tanpa harus memulai dari nol.

## ✨ Fitur Utama

*   **Desain Responsif:** Tampil sempurna di perangkat *mobile*, *tablet*, maupun *desktop*.
*   **Informasi Mempelai:** Profil singkat dan foto kedua mempelai.
*   **Detail Acara (Akad & Resepsi):** Waktu, tanggal, dan lokasi acara.
*   **Integrasi Peta:** Peta lokasi acara menggunakan Google Maps untuk memudahkan tamu.
*   **Hitung Mundur (*Countdown*):** Timer hitung mundur menuju hari-H.
*   **Galeri Foto:** Menampilkan momen *pre-wedding* atau foto-foto kebersamaan.
*   **Formulir RSVP & Ucapan:** Memungkinkan tamu mengonfirmasi kehadiran dan memberikan doa/ucapan.
*   **Pemutar Musik:** *Background music* otomatis untuk menambah suasana romantis.
*   **Protokol Kesehatan / Catatan Tambahan:** Bagian khusus untuk informasi penting lainnya.

## 🛠️ Teknologi yang Digunakan

*   **HTML5 & CSS3** (Atau sebutkan *framework* jika ada, misal: Tailwind CSS / Bootstrap)
*   **JavaScript (Vanilla)** (Atau sebutkan jika memakai React/Vue/Svelte)
*   **Font Awesome** (Untuk ikon)
*   **Google Fonts** (Untuk tipografi yang elegan)

## 🚀 Cara Instalasi dan Penggunaan

Jika proyek ini adalah web statis biasa (HTML/CSS/JS):

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username-anda/undangan-pernikahan-digital.git
   ```
2. **Buka folder proyek:**
   ```bash
   cd undangan-pernikahan-digital
   ```
3. **Jalankan secara lokal:**
   Buka file `index.html` langsung di browser Anda.

*(Catatan: Jika Anda menggunakan Node.js atau framework seperti React/Next.js, silakan ubah instruksi ini menjadi `npm install` dan `npm run dev`)*.
